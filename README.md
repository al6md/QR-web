# مولّد رموز الاستجابة السريعة المتقدم | Advanced QR Code Generator

تطبيق ويب حديث ومتطور باللغة العربية لإنشاء وتخصيص رموز الاستجابة السريعة (QR Codes) مجاناً وبدقة فائقة تصل إلى 4K، مع احترام كامل للخصوصية وتوليد محلي 100% داخل المتصفح.

![QR Generator](https://images.unsplash.com/photo-1595079672139-62394d7b3f95?auto=format&fit=crop&w=1200&q=80)

---

## ✨ المميزات الرئيسية (Key Features)

- 🔗 **دعم شامل لكافة أنواع البيانات:**
  - روابط المواقع (URLs).
  - شبكات الواي فاي (Wi-Fi) مع التشفير التلقائي.
  - بطاقات العمل الرقمية (vCard) المتوافقة مع الهواتف الذكية.
  - الرسائل النصية القصيرة (SMS) ورسائل WhatsApp المباشرة.
  - البريد الإلكتروني والاتصال الهاتفي والمواقع الجغرافية.
- 🎨 **تخصيص فني احترافي:**
  - أشكال متعددة لنقاط الرمز والزوايا والأطر الخارجية.
  - ألوان مخصصة وتدرجات لونية خطية ودائرية (Linear & Radial Gradients).
  - إمكانية رفع شعار مخصص (Logo) في المنتصف مع تحكم دقيق بالحجم والموضع.
- 🚀 **تصدير فائق الدقة (Ultra HD & Vector):**
  - دعم التصدير بصيغ `PNG` و `SVG` و `JPEG` و `WebP`.
  - خيارات دقة متعددة تصل إلى **4096 × 4096 px (4K)** مناسبة للطباعة الضخمة واللافتات التجارية.
- 🔒 **خصوصية وأمان 100%:**
  - تتم معالجة وتوليد كافة الرموز بالكامل على جهاز العميل (Client-Side) دون إرسال أي بيانات لخوادم خارجية.
- 📋 **أدوات سريعة وسجل محفوظات:**
  - نسخ مباشر للصورة إلى الحافظة وطباعة فورية بنقرة واحدة.
  - سجل محلي لجميع الرموز التي تم تنزيلها مع إمكانية استعادة إعداداتها وتعديلها.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 15+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Modern Neo-Brutalist Aesthetic)
- **Icons:** Lucide React
- **Typography:** Cairo Arabic Google Font
- **Animations:** Motion & Canvas Confetti

## 🚀 التشغيل المحلي (Getting Started)

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/al6md/QR-web.git
   cd QR-web
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run dev server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. **بناء المشروع للإنتاج (Build for production):**
   ```bash
   npm run build
   npm run start
   ```
